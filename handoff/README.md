# GK PilePro Team Handoff

Thu muc nay dung de ban giao cong viec theo tung mang. Khi gui source cho nguoi khac, dua ho xem thu muc dung voi phan viec cua ho truoc.

Moi folder con co thu muc `source/` chua san cac file lien quan den mang do, giu dung cau truc duong dan cua project goc.

Luu y: source chay that van nam o root project, `app.py`, `gk_pilepro/`, `assets/`, va cac file `.spec`. Thu muc `handoff/*/source/` dung de ban giao theo mang; neu nguoi nhan sua trong do thi can copy/merge lai dung duong dan tuong ung o project goc.

## Cac mang

- `01_User_Client`
- `02_Admin_Client`
- `03_Presence_Update_Server`
- `04_Gemini_OCR_Service`
- `05_Excel_Data_Files`
- `06_Local_App_Data`
- `07_Build_System`
- `08_Assets_UI_Resources`

## Cach giao viec

1. Gui ca folder project cho nguoi nhan.
2. Bao nguoi nhan mo dung folder trong `handoff/`.
3. Nguoi nhan xem/sua cac file trong `source/` cua mang do.
4. Neu can sua ngoai pham vi, phai hoi nguoi quan ly project truoc.

Tai lieu day du: `docs/OWNERSHIP.md`.
